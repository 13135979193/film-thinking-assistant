# 来源、状态与使用范围

本包是对原作者本地已保存的影视工作记录、纠错意见、光影学习资料和空间风格研究的文字蒸馏。资料被改写为判断依据、操作方法、失败边界和匿名案例，不附原剧本、客户项目文件、原参考图片、账户配置或书籍全文。

版本 0.2.0 补入 [反馈证据与蒸馏对应](feedback-evidence.md)：20 个带日期和出处标识的记录片段或摘要。短句按“记录内引用的用户用语”标注，未声称对原聊天逐字核验。要求/常见失败清单也不再混称为已发生且已验证的失败事件。

## 经验与知识来自哪里

- **个人工作方法与纠错：** 项目 AGENTS 记录、专门纠偏/重建/连续性/学习记录、影视资产助手工作约定和建筑偏好。人物流程也参考既有选角技能中的身份、肤质、单图与多视图规则。旧项目具体名字、数字与格式不作为新项目通则。
- **光影：** 本地 Lighting for Cinematography 学习库中的现代 35 章、基础章节、诊断练习、词汇与历史阅读资料，以及影视资产助手的光影工作约定。书籍与研究属于外部知识来源；本包的表达是整理与改写，不宣称相关光学知识由作者原创。
- **空间：** 建筑风格学习库中的已验收卡、候选研究和反馈，以及五类场景设计资料。建筑卡中原型来源、可见观察与原创设计动作为不同层次；保留必要来源链接。

来源日志与具体文件覆盖清单保留在制作方的本地核查记录中；分享包的日常调用不依赖那些本机路径。

本次整理覆盖项目经验记录 996 行、77 份非每日日志的工作材料和检索命中的 6 份明确反馈日记录。77 份中 71 份全文读取，其余 6 份含大量候选元数据、原剧本或资产索引，按结构、方法和反馈段处理，不把原始材料当作已验证知识。光影库 74 份 Markdown 全文读取；建筑库 32 份 Markdown 全文读取，保留其 9 项正式验收和 18 份未正式验收材料的区别。

## 哪些状态不能混淆

| 状态 | 含义与使用 |
| --- | --- |
| 来源中的明示事实 | 原记录或来源写明；未必已在本次重新独立核实 |
| 图像可见观察 | 当时记录实际观察的结构、光影等；没有原图时不能声称本次看过 |
| 原作者认可 | 当时用户认可的具体方案或维度；不是适合所有任务的证明 |
| 局部认可 | 仅限指定部分，其他机位、连接或整体可能仍需检查 |
| 原创设计或合理补设 | 用于生成的创意，不作为历史建筑事实 |
| 待验收或已否定 | 研究起点或反例；不能包装成成熟成功方案 |
| 跨任务通用方法 | 从记录提炼的工作原则；仍需对本次条件与结果核对 |

建筑知识图谱中，正式索引有 9 条记录；另有 18 份候选文件，其状态包括待验收、局部认可和已否定。不能把文件数量当成掌握数量。

## “整合思想方式”的边界

已写下来的偏好、纠正、选择理由和知识可以整理为可调用的方法。没有保存的想法、未能访问的历史聊天、图片中未提炼的信息及人的临场经验不能被声称已经完整收录。本包没有训练或转移模型参数。

蒸馏保留理由与适用条件，不保证每次生成自动正确。提示词检查、实际图像检查、原作者验收、同事在新任务中的表现是不同验证层次。当前版本不宣称已完成真实生图或同事使用验证。

普通知识查阅与提示词交付可直接使用；涉及精确灯位、实际施工、历史地域断言或完整还原未见背面时，以可用证据和本次核查为准。无证据的精确数值不由蒸馏补成事实。

多人使用时保留当前项目自主选择。某位同事的新意见只有在授权更新共享版本并核对适用范围后，才加入通用规则。
