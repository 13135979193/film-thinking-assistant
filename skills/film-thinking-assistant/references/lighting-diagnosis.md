# 光影诊断：证据、假设与最小修正

用于看图反推、日夜检查、空间换角度、合成与 AI 错光修复。设计原理见 [光影原则](lighting-principles.md)，写法见 [词汇与句式](lighting-vocabulary.md)。先确认本次要的是分析、修图提示词还是实际编辑；不能把写过指令当成完成编辑。

## 先限定要解决的问题

记录需要保留的身份、动作、摄影机、房间体量、布局、材料与认可风格。然后把用户反馈转成一个可检查的问题，例如“暗侧眼睛看不清”“台灯方向与桌面投影冲突”“画面均匀发亮、没有空间深度”。“更高级”“不够电影”需要落到注意力、形体、材质或时间感，不能直接套大对比和蓝橙配色。

先辨认媒介与创作意图。剪影、舞台多光、彩色照明、超现实画面可以故意改变常规关系；只有违反本画面已确立的逻辑或用户目标时才算问题。全黑导致关键动作不可读、窗口剪切遮住必须交代的内容等严重问题先处理，不机械地把曝光留到最后。

## 反推图片的七步

1. **定坐标和物体。** 标出摄影机观察方向、主体朝向、地面／墙面、窗门、可见灯以及主要遮挡体。把屏幕左／右与房间世界位置分开；看不到的区域保持未知。
2. **写可见证据。** 找至少两类能相互核对的线索：同一物体的亮暗面、投影起点和落点、半影、眼神或材质反射、局部衰减、反弹颜色。最高亮点只作为线索之一，不直接定位灯。
3. **先解释来源类别和方向。** 用遮挡体、投影面和投影反向关系估计入射方向，再看鼻影、家具受光及开口是否支持。投影经过透视或斜面后会改变画面方向；不要仅按二维箭头判断。
4. **分别判断软硬与距离。** 阴影过渡能限制有效角尺寸，但也受遮挡体到投影面的距离、反射和后期影响。前后亮度变化可能来自近源、遮挡、材质或局部补光；“软”不能唯一证明“近”，“背景暗”不能唯一证明“衰减快”。
5. **补出间接路径。** 检查浅墙、桌面、地面、天花、雪、水及服装是否可把光带到暗侧。镜面高光需考虑观察角；彩色暗部可能来自反射，也可能来自另一个来源或调色。
6. **解释空间与记录。** 判断背景与人物如何分离，关键灯／窗是否失去细节，暗部是否保留必需信息。相机曝光、色彩响应和后期无法从单张成片可靠还原，只写它们可能造成的影响。
7. **给最少的可行假设。** 优先选能解释最多证据的来源关系；不足时再考虑第二来源。给出最可信方案及关键未知处，必要时列一项替代解释，不为了补全表格杜撰完整灯单。

单张图通常只能反推可能的照明条件。源尺寸与距离可能形成相同角尺寸；灯、扩散面与反射墙也可能形成接近的结果。没有已知尺度、现场记录或测量时，不报精确米数、瓦数、色温、光比或机型参数。黑白复制图尤其不能提供可靠原始色温。

### 简短证据格式

| 层级 | 应如何写 |
| --- | --- |
| 当前画面可见 | “桌脚投影从桌脚向右后方延伸；左侧桌沿较亮。” |
| 来源明确记载 | “来源记录给出了窗外灯的位置。”只在实际读取到该记录时使用。 |
| 支持较强的推测 | “较可能有左前上方方向光，可同时解释桌沿与地面投影。” |
| 尚不能区分 | “柔和暗侧可能是白墙反弹，也可能是画外弱补光；图中无法确定。” |
| 创作建议 | “可保留左窗为主来源，以浅墙反弹抬暗侧。”不是原现场事实。 |

历史笔记里的“已观看”“已读全书”“图片可见”仅是旧记录，不等于本次完成了同一验证。无法打开的参考只能按已提供文字讨论，不声明重新观察到细节。

## 常见症状：先鉴别，再修

| 症状 | 先排除的解释 | 优先处理 |
| --- | --- | --- |
| 空间平、所有面相近亮度 | 是否原本就要均匀展示；材质或构图是否缺少分层 | 减少无方向填充或溢光，让开口、遮挡与局部亮区建立纵深；不自动加轮廓灯 |
| 脸或建筑轮廓像贴在背景上 | 背景颜色、亮度、空间距离是否与主体相近 | 选亮度、色彩、背景纹理或有依据的边缘光之一做分离 |
| 标称柔光却有硬影 | 有效面是否小；是否另有直射太阳；影是否来自另一源 | 扩大实际受亮面或靠近扩散面；处理直射路径，不只降低强度 |
| 灯具很亮、人物却暗 | 灯罩是否遮住人物；距离和出光方向是否合理 | 分开控制画内亮度与所需主体光，沿来源逻辑增补或改变主体位置 |
| 暗侧没有表情 | 是否需要剪影；顶光眼窝与暗部记录是否失去信息 | 局部抬必要反弹或调主光高度，保留其余暗区 |
| 脚或道具像悬浮 | 实际是否离地；地面是否与物体共享透视与尺度 | 先修接触／几何，再加连续、强度适当的接触遮挡与投影 |
| 一物有两条影或多个眼神光 | 是否有两个可解释来源；窗与灯能否同时照到 | 有依据就保留，若无依据再去掉多余路径或减为弱填充 |
| 金属／玻璃亮侧与脸不同 | 镜面角度、材质粗糙度、另一个来源是否能解释 | 先检查反射几何；确认冲突后再改，不强迫所有材料同一亮面 |
| 夜景像统一蓝滤镜 | 是否来源真实偏蓝；空间仍否保留材质与亮度区别 | 建立主导来源、局部可见性和暗部层次，按区域处理色彩 |
| 画面“CG 味”过重 | 是否本就要求 3D 媒介；是否塑料高光、黑缝或统一描边 | 保留建模体积，降低过重 AO、均匀边光和不合材质的反射；不改成 2D |
| 演员走动时曝光突跳 | 是否跨越窗门等真实光区；近灯距离变化是否过大 | 调覆盖、相对距离或光区过渡；保留剧情需要的明暗变化 |
| 反打后主光换边 | 屏幕坐标是否因机位改变；演员是否转身 | 按房间固定源重算受光面和反射，不能按“画面左光”逐镜硬套 |
| 灯／窗剪切、黑位发灰 | 局部高光是否重要；是否眩光、曝光或后期曲线问题 | 按需要压来源、切直射镜头光或重设亮度范围，避免全场一并变暗 |
| 人脸莫名绿／橙 | 彩墙反射、灯光光谱、白平衡或混色是否造成 | 先定位区域与来源，再修溢光或颜色；不把全图统一加暖当补救 |

“最亮的背景抢戏”也不是绝对错误：亮门、亮窗可用于剪影或出口叙事。评价的是观看路径能否交代本次信息，不是主角必须占最高亮度。

## 修复次序按主要错误分支

**几何或方向矛盾：**锁定最有依据的来源 → 检查遮挡与直接受光面 → 重建投影 → 修接触、反弹与镜面反射 → 再看背景、颜色和曝光。新增人物／道具要同步处理手、桌、地面及相邻物体，不只改一张脸。

**方向成立但“不自然”：**先查材质响应、扩散面、暗部反弹和溢光；再决定是否减少均匀填充、背景同亮度或过强轮廓。用最少变化恢复局部差异，不能为了自然光把用户认可的宏大体量和设计形状削掉。

**太暗、过曝或偏色：**确认关键区域的记录与可读性 → 判断是光量、遮挡、眩光还是调色 → 调需要的区域 → 复查方向和空间。不能把提亮黑位当加反射、把降高光当灯位修正，或承诺恢复原本未记录的细节。

**昼夜与换角度：**建立同一房间、材料和世界光位 → 明确哪些来源允许改变 → 为新机位重算可见高光、投影及开口 → 检查变体。日夜可改变天空和灯的状态，不能顺手换家具、移动窗或改变建筑层数。

修正会相互影响：源变大既改变半影也可能改变反射，减反弹会改变暗侧颜色，移动灯会改变背景。一次编辑尽量围绕一个主要问题，修完重新检查关联区域；不保证“一次只改一个词”就能让生成模型仅改变一个像素维度。

## 如何把修复要求写成可执行交付

简任务只给一条主要诊断和完整可复制指令，不强制灯位图、负面词或长表格。复杂合成可增加“保留／修改／验收”三个字段：

- **保留：**当前相机、结构、家具位置、人物身份、动作与已经认可的风格。
- **修改：**明确哪一个来源、哪一面、哪个投影或反射需要怎样改变；把允许的亮度与颜色变化限制到相关区域。
- **验收：**核查原问题是否改善，同时检查保护对象、接触关系、材质与背景；实际观察结果后才说完成。

例如：保留当前左侧高窗与全部布局；让桌、椅及地面投影由该窗方向一致地产生，暗侧仅接收克制的浅墙反弹；恢复桌脚接触地面的局部阴影，削弱无依据的右侧冷亮边。这个要求没有重设计房间，也没有声称知道现场灯具功率。

若要反推复现，可说“下面是一套能产生类似关系的设计”，另注明哪些参数是建议起点。若要实际修改，必须有可访问的目标图和编辑能力，完成后查看结果；只有输出提示词时明确交付的是指令。

## 结果检查与小规模练习

以当前目标选择两到四项检查即可：来源和投影能否互相解释；接触和反射是否成立；关键动作／表情／路径是否可读；主次与媒介风格是否保持；反打或日夜变体是否仍为同一空间。评分表不能代替看图，不用“所有项目合格”夸大验证范围。

可用简单物体做三种对照：固定相机与记录方式只改源方向，看投影变化；固定有效面改变距离，看主体与背景变化；固定主光只换白／黑反射面，看暗部变化。尺寸、距离或曝光若是真实测量就记录；否则标为练习设定。这样建立可验证的判断习惯，比积累一组默认角度更能迁移。

生成图片仍可能误读、漏改或改变保护对象。若结果没有出现所需关系，回到实际图像找主要失败，缩小本次修改并复核；不要把更长的术语清单当成成功证据，也不要声称已有唯一正确的逆向灯单。
