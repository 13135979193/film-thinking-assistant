# 五类场景用途库

类别负责世界、用途与动作，风格负责体量、结构、开口和工艺。先从任务确定地区/时期、身份、真实或幻想世界、用途与主要动作；相邻类别可组合。具体建筑语言按[空间图谱](space-atlas.md)的状态调用，几何与换视角按[空间原则](space-principles.md)执行。

例如哥特校舍同时用欧式类型和教育功能；水下宫殿先确定水气边界再安排礼仪路线；豪华船舱先守船体再选室内语言。历史壳体可改作现代用途，但须解释改建层。以下是设计方法与原记录经验，不能替代精确年代、文物测绘或工程资料。

## 1. 欧式庄园、哥特、宫殿与豪华客轮

先分国家、故事时期、兴建/改建层、阶层与用途。尖拱、壁炉、镀金和水晶灯不是一套万能欧洲语法；哥特原作、哥特复兴、巴洛克、洛可可及维多利亚等标签须分别有依据。

| 类型 | 功能与路径 | 空间表达 |
| --- | --- | --- |
| 生活型庄园 | 门厅分向会客、餐厅、私人翼；服务庭和后台另行连接 | 楼梯高差、连续门洞视线、窗边家具群、书墙与织物形成生活密度；房间顶面随用途有差异 |
| 哥特外壳/公共厅 | 门槛经柱列/拱券到主功能，侧廊承担分流 | 深窗洞与竖向节奏交代厚墙；窗光显出构件，不默认阴暗破败 |
| 宫殿礼仪空间 | 抵达、等候、主位形成等级，侧向服务与私密区相接 | 厅室序列、墙面模数、顶墙连续工艺建立礼仪距离；家庭寝室另按生活功能 |
| 豪华客轮 | 先标甲板、船首尾、左右舷，再分乘客/服务流与垂直交通 | 船体范围内组织楼梯、餐厅、客舱、走廊和甲板；固定家具、舷窗与通风随船型核对 |

住宅不能全部变接待大堂，船舱不能无限扩成陆地宫殿。舱等决定材料与服务，厨房/工程舱不沿用头等舱金饰；某艘船的两组楼梯与固定甲板关系不作所有船的标准。需要复原具体船舶时查那艘船的布局。

洛可可可让曲线细部在重复墙面模数内展开，由门洞、镜面、壁灯和画框保持秩序；淡底、局部金属、深色焦点仅为可选方案。穹顶/高窗/舷窗给定自然光路径，阅读和用餐灯承担使用焦点；设施与电光须符合时期。更华丽仍应保留室内功能和清楚路线。

## 2. 公共、工业、交通与地下设施

先确定服务/生产任务和时代技术，功能链决定门禁、标高、设备与结构。现代医院、历史车站、未来设施不共用一套设备。

| 用途 | 功能骨架 | 设计感落点 |
| --- | --- | --- |
| 学校/图书馆/博物馆 | 入口辨向后到使用区、上层与后续出口，后台按需独立 | 教学组团、书墙/展墙、挑空、重复柱跨和可达楼梯共同导向 |
| 医院/法院等受控空间 | 公共入口到等候、受控界面、专业区；业务分流 | 门槛和材质分区说明权限，不能用酒店装饰代替服务功能 |
| 工厂/能源/水处理 | 进入或来料到加工、控制/检验、储运/排放 | 设备尺度、梁跨、维护猫道、吊装净空、天窗和管线组织形成秩序 |
| 车站/港口/交通枢纽 | 城市侧抵达，经办理/候乘到登乘和载具侧 | 柱列、顶棚、平台标高与轨道/岸线共同指方向；客货流按任务分开 |
| 地下站/矿井/地堡/蓄水设施 | 下降入口接主路线、工作节点和后续出口 | 支护/拱跨、平台、排水及任务光交代深度与可维护性 |

宏大通过结构重复、设备/座席容量、长轴目的地和服务空间证明；纪念性大厅可以低密度，生产设施需要真实功能密度。维护路线不可被构件或陈设堵住。安检、电梯、消防设施随年代核对，概念提示词不冒称合规。

工业不必锈蚀，地下不必潮湿，医疗不必阴暗。湿面、蒸汽、尘或废弃状态只由剧情/环境支持。正常高端学校不借废弃教室作基准；照片标签写library也不能证明实际用途，结构可借、身份另证。

## 3. 人鱼与水下幻想

这是世界设计。先选**全浸水、干式围护或两栖潮汐**，混合时标出边界；魔法可改变约束，但要全片一致。普通玻璃外观不能证明水下结构可行。

| 生活媒介 | 建筑必须回应 |
| --- | --- |
| 全浸水 | 竖向游动井、分层停留平台、洞口、避流位置与远距寻路；书籍、织物、食品和灯火按水下使用改造 |
| 干式舱/穹顶 | 围护、水气分界、入口和连接结构清楚；室内陆地功能必须有维持条件 |
| 两栖洞窟/潮汐 | 固定水线、停留台地、湿干连接、上升入口与采光通风；跨镜头潮位有统一基准 |

宫殿用受保护主位、礼仪接近和上下层距离；住宅/城市有生活单元、交通和维护；市场/港门有停靠、装卸、储藏与交易；图书馆说明资料保存媒介；监狱与剧院处理三维移动的门禁/观察或观演路线。沉城是在可辨旧功能的骨架上叠侵蚀、生物附着，不是随机遗迹。

从岩腔、壳体、竖肋、台地、桥管、层叠开口选一个主结构，再让珊瑚、贝壳、珠母或生物光成为局部材料层，避免平均铺满。生物/魔法承重在视觉上仍要表达连接。浅海天光与深海自发光有不同来路，水深/浑浊度决定焦散和颗粒；不能所有海底加相同波纹、蓝绿洞穴或吞结构的雾。旧项目神明、国家配色和纹样不转为新世界通则。

## 4. 中国古建、清宫、府邸与园林

先限定朝代/时期、地域、身份等级和用途。已有经验偏清宫和府邸园林，不能当整个中国建筑史；屋顶、彩画与等级要有相应资料。

| 类型 | 组织依据 | 容易失准处 |
| --- | --- | --- |
| 外朝/礼仪殿院 | 院心、台基主殿、左右围合与礼仪轴，侧向服务可达 | 园林水池或家具岛侵入应完整使用的礼制院心 |
| 内廷居住院 | 宫门、院落、廊檐、明间再到侧间/寝区，私密渐进 | 把居所做成缩小最高等级大殿 |
| 王府/权贵家宅 | 礼仪中路和居住/花园侧路，多进院落相连 | 任意下放皇宫红墙黄瓦或龙纹规格 |
| 园林生活院 | 厅堂、廊、墙、水、曲径及后续门洞相接 | 大空石院替代园景，或孤亭、假山、池塘随意拼摆 |
| 普通院落/辅助建筑 | 当地材料、家庭生产生活及有限维护资源 | 一写古建就宫殿化，贫困就垃圾化 |

已有局部认可的生活园林方向：近处自然枝叶/栏石边，中部曲径及侧窄水面，远处厅堂和廊道，再远门洞/屋脊；边缘有密度，主路仍可走。只在相容园林调用，不能覆盖用户要正视或礼仪广场的任务。寝区、桌案、屏风、榻床、柜架按功能落位，不固定为旧模板位置。

白天利用庭院—深檐—窗侧—内室的过渡；格扇影对应实际开口。灰瓦深木青灰石与低饱和植栽是已有园林方向，不作所有古建配色。现代灯带、筒灯、玻璃系统和异地域构件须有剧本依据；影视美术图不能当文物测绘。

## 5. 北美普通住宅、社区与日常商业

细分国家、地区气候、故事年份、收入与家庭结构。北美、美国、加拿大及欧美居住不是同一种住宅；本库细分年代地域证据较薄，具体复原需补查。

| 类型 | 路线/使用关系 | 可用设计动作 |
| --- | --- | --- |
| 独立屋/小镇老宅 | 街道经院界/门廊入户，接起居餐厨与私密区；后院楼梯随房型 | 开口节奏、旧新家具、阅读角、织物和木作呼应 |
| 公寓/租住空间 | 公共入口/走廊再到入户、生活与私密区 | 收纳、紧凑家具群、窗侧使用位和维护痕迹，面积与收入一致 |
| 住宅街/社区 | 步行、退界、门廊/车道、路口和围栏/绿篱按地区组织 | 重复房屋中有差异，植被边界和前后尺度支持寻路 |
| 咖啡/小餐饮 | 店面到点单、等候、取餐和座席，接备餐/储藏 | 窗光、吧台与成组座位确立业态，服务流不穿座区死角 |
| 商店/日常服务 | 街面到浏览/服务、结账和后台补货 | 货架尺度、局部陈列与街道开口，不自动升级奢侈旗舰店 |

普通住宅的个性可来自一处主锚点及材质/颜色呼应，不靠改豪宅；家庭人数与实际会客、影音、餐厨、工作决定家具密度。夜景应有生活使用点和可读环境；台灯、窗和顶灯随房型真实配置。漏水、维修、雨天、节日属于状态，保持固定布局。破旧程度取剧本，不把低收入变废墟。

普通卧室与主卧/次卧关系按当前家庭和房型判断，不搬旧项目绝对尺寸；社区商铺的资料不足不能靠大量高端夜店图补足，欧洲石巷也不能证北美普通住宅街的时代。

## 快速调用

只选任务需要的类别，不要求用户先在三套风格中选择。用“用途链＋一种相容的建筑语言＋一个主空间动作”形成提示词；纯提示词任务保持输出简洁。若类别重叠，世界物理与地域时期是边界，用途是骨架，审美灵感落在结构/开口/材料/密度上；不为套库更改当前剧情。
