# 剧本、人物、服装、道具与交付

## 剧本资产先有证据，再有设计

读取本次提供的完整剧本，记录已读集场。缺页、附件无法解析或只收到片段时，交付范围与实际阅读一致。先建立集场索引，再提取资产；不要用美术想象填补剧情事实。

| 资产 | 提取与核对 |
| --- | --- |
| 人物 | 身份、别名、关系、外貌依据、出现集场；同人别名可合并，同名异人分开 |
| 场景 | 归属、独立功能空间、内外景、年代地域、故事时段、动作、相邻关系、出现集场 |
| 道具 | 实际使用、递交、持握、驾驶或破坏的关键物件；归属、状态、数量依据和出现集场 |
| 服装 | 人物、套装与搭配、故事时间、换装原因、湿脏破损修复等有依据的状态 |

给批量资产稳定 ID，关联原文集场与简短证据。区分同一地点的昼夜状态、独立房间、建筑内外景和不同归属的同名地点；车辆也要按归属及用途辨认。普通布景陈设不一律升级为剧情道具。

完整资产表未规定模板时可采用人物、场景、道具、服装接戏四类；用户模板和实际需要优先。交付前核对原文覆盖、别名、功能空间拆分、资产引用和状态连续性。数量只报告实际核对结果。

## 场景生成描述

先从剧本或当前要求取得地域、年代、阶层、用途、动作及媒介风格，再选空间与光影资料。一个剧本里的学校、住宅、车厢、市场不能套同一种装修模板。

组织提示词时，让场景身份、摄影机、固定空间、可见相邻关系、主要陈设、材质与有源光互相支持。先有可理解的空间，再有装饰密度；具体取舍见空间原则。单图只有一个明确时段，昼夜各写完整变体。

仅有场景名时，先检索本次可用原文；没有原文则按名称设计并标明假定，不虚构它在剧中的剧情。已经认可的空间继续作为基准。

## 人物与造型

从身份、年龄、职业、地域、生活状态和当前媒介风格建立人物。对写实人物，肤质应保留细微纹理与自然层次，避免蜡感、塑料感、整张脸同色或油亮白斑；面部信息和眼神要可读。环境暖光或彩光不能无依据地把肤色染成均匀黄橙或脏绿；用户要求强烈彩光造型时，按其目的控制局部受光，而非机械消除所有颜色。

批量角色通过骨相、眼眉间距、鼻唇结构、年龄感、头发、身形和姿态形成身份差异；剧情亲属可有家族相似，仍要可辨。不要用一个通用美颜脸代表所有人。已经认可的角色换装或换角度时，以该角色为身份基准，不再改五官。

普通人物请求按指定构图交单人形象；只有要求三视图、角色拆解或多视角时才做。多视图检查同一人的骨相、发型、标记、肤色、身形与衣服是否一致，不能以文字声明替代看图。

使用参考时先说明参考提供身份、轮廓、衣服结构、姿态还是光线。单张图未展示的信息属于补设；没有可访问素材库时不能声称调用过。用户有明确同人续作基准时保持身份，原创角色设计则从多维造型信息形成新的、明确的人物。

服装以年代、地域、阶层、职业、季节和动作决定裁片、轮廓、面料、穿法与磨损。复杂题材应区分史料依据与创意造型；不要凭标签认定年代。道具写清使用方式、人体尺度、结构、材料与状态，避免只有华丽名词却无法握持、连接或使用。

## 接戏与批量状态

接戏记录连结资产 ID、角色或归属、集场、故事时间、服装搭配与状态变化。同一剧情时间是否换装以原文或明确指示为准。湿脏破损、修复、物件转移都有依据；不能擅自增添剧情。

大批量任务维护认可版本和需要修改的项，提交文件前检查表格与资源是否能打开、内容是否完整。简单单条提示词不要求额外维护一整套项目文档。
