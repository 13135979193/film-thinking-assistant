# 场景设计与图像生成

## 生成前的分析卡

每个独立空间明确：原编号和原文位置；年代国家及证据强度；谁拥有/使用；身份、财富来源、性格；剧情动作与关键陈设；适配风格和理由；平面组织、层高尺度；主辅点缀色；材质；日夜和真实光源；摄影方向；待核事项。

先回答“这是谁的房间，为什么住在这里”，再回答“装修成什么样”。欧洲贵族、英式家族宅邸、都市精英大平层等只是候选，不能仅凭男主有钱便套用。豪华感来自比例、材料规格、定制细部、工艺和陈设层次。医院、廉价公寓遵守剧情身份，不全剧升格。

## 空间与配色

- 默认场景资产无人、真实摄影质感、16:9、自然平视正面全景、门关闭；用户要求和原文动作覆盖默认。正面全景保留透视纵深，不是无透视施工立面。
- 要求宽阔时用层次、套间、侧向延伸、窗湾、退进或合理功能分区组织空间；避免只有四面平墙的空盒子，也避免无意义曲墙。
- 宽阔而不空荡：主家具、次功能区、地毯和灯具形成尺度关系，保留动线和拍摄空间；不用满地小摆件掩盖比例问题。原文狭小则保持狭小。
- 门窗开合、楼梯连接、家具尺度、镜像反射须符合物理空间。
- 先选适配角色与地域的主色，再选木材、石材、织物、金属；用材质层次丰富画面。不能用整屋橙黄光、大块高饱和色或强烈滤镜替代设计。
- “不适合男主”须重查人物与参考，不只随机换色。历史认可过的暖白、燕麦、胡桃木仅是原项目经验，不是通用默认。

## 查参考与提示词

用户要求上网或风格不确定时，查实际建筑、室内、品牌案例。优先建筑师、设计事务所、酒店或品牌官网，实际打开图片看空间和配色；不能把搜索摘要当看过图片。记录参考链接与借鉴点，提取空间语言，不照搬整张作品。

提示词顺序：地点与归属 → 年代地域和建筑语言 → 空间组织 → 主要家具位置 → 材质配色 → 灯光来源 → 摄影方向画幅 → 必要排除项。使用可见描述，不堆“顶级、极致、8K”。中文或英文按用户及工具选择。

审代表图：身份贴合、颜色协调、豪华程度恰当、空间宽阔且充实、正面构图成立、建筑可信。用户认可后保存图片与判断作为后续实际参照；没有参考图片时说明限制。

## 连续性与反馈

同场景变体记录原空间编号，另设图片编号如 S001-NIGHT-v02。换机位锁定门窗、家具、层高与连接关系；真反打展示相对一面，不能仅镜像原图。改日夜锁定布局和世界中的光源位置。

判断反馈针对身份、建筑、布局、颜色、材质、照明还是构图，只改对应维度；要求推翻时才重建。保留旧版本可追溯，最终目录只收选定版本。否定两轮且无明确方向时查新参考并说明变化，避免无依据随机换色。

每张最终图实际打开查看；文字、门状态、异常结构等放大检查。局部问题可修图，大规模布局错误应重做。状态 generated、checked、user_approved 分开：checked 表示执行者已检查，不等于用户认可。
